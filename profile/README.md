## What Is ColorAnt

ColorAnt is a measurement helper that sits before a printer profile is built. ColorAnt measurement data is the raw material: numbers from a chart, not a picture. ColorAnt smooth correction and ColorAnt optical brightener are ways to make those numbers less misleading. A home printer user, a photography class, or a small shop can clean a reading before they ask another tool to build a profile.

ColorAnt wedge compare is the check you do when a short control strip was printed with the job. ColorAnt report view is what you save so next week’s person can see what was changed. The aim is trust in the numbers, not a prettier chart for its own sake. If a patch was misread, fixing the data is more honest than hoping the profile averages it away.

Load ColorAnt measurement data, look for spikes, then try a light ColorAnt smooth correction. Use ColorAnt optical brightener only when the paper is brightened and you know the viewing condition. Run ColorAnt wedge compare on a strip from the same print, and keep ColorAnt report view with the chart file.

## Starting with ColorAnt

Prerequisites: A compatible computer, a measured chart you are allowed to use, and permission to run ColorAnt.

1. **Prepare:** Confirm the chart, the paper, and the meter before you open the file.
2. **Load The Readings:** Import them as ColorAnt measurement data and look for obvious spikes.
3. **Smooth Lightly:** Apply ColorAnt smooth correction and compare the before and after on a few patches.
4. **Paper Glow:** Use ColorAnt optical brightener only if that paper is brightened and the viewing light is known.
5. **Check A Strip:** Run ColorAnt wedge compare if the job included a control wedge.
6. **Save The Note:** Export ColorAnt report view and keep it beside the measurement file.
